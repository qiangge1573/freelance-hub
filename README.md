# Freelance Hub (私活网)

自由职业者任务对接平台原型 —— 一个纯前端实现的私活交易网站概念版。

## 功能模块

- **任务大厅**：浏览各类私活任务，支持按分类（开发/设计/文案/运营）筛选
- **发布任务**：完整的任务发布表单（标题、分类、预算、截止日期、技能要求、详细描述）
- **技术论坛**：社区帖子列表，支持分类tab（接单晒单/避坑经验/技术交流/需求吐槽）

## 技术栈

- 原生 HTML / CSS / JavaScript
- 单文件实现，无构建工具，无依赖
- Hash 路由多视图切换
- 响应式设计，适配桌面和移动端

## 预览
